# NFTNook

A simple NFTNook Service for Auto scaling.

With NFTNook, you get a lightweight tool that stays out of your way.

**What you get**

- A simple NFTNook Service for Auto scaling

## Key Features

- A simple NFTNook Service for Auto scaling

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/NFTNook.git`
2. `cd NFTNook`
3. Install in editable mode: `pip install -e .`

## Configuration

NFTNook is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
